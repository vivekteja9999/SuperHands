# SuperHands
We deliver you not just the app/website, We deliver you the company.

Turn your idea into a website, app, or piece of software — and a company you actually run.
SuperHands is an AI-first platform designed to bridge the gap between building a product and running a business. Instead of just delivering code or design prototypes, SuperHands builds your software and staffs it with autonomous AI agents that manage day-to-day operations under your supervision.

🚀 Overview
Building a website, app, or piece of software is only half the battle; running it daily requires operational effort, customer management, and constant oversight.
SuperHands handles both sides:
Builds your product based on simple natural language prompts and adaptive follow-up questions.
Staffs your business with specialized AI agents (e.g., Bookings, Refunds, Waitlists, Support).
Puts you in control with customizable operational hierarchy and flexible Human-in-the-Loop (HIL) controls.

✨ Key Features
Prompt-to-Company Creation: Describe what you want to build in plain English—whether it's a booking system, subscription D2C store, or internal tool—and let SuperHands handle the scaffold and logic.
Hybrid Org Charts (Humans + AI): Define clear hierarchies where AI agents and human managers work side by side with distinct authority and reporting paths.
Human-in-the-Loop (HIL) Controls: Route critical decisions (like refunds over a specific dollar amount or sensitive approvals) directly to human team members before execution.
Dual-Level Control (Code & Natural Language):
Engineers: Modify workflow code directly in TypeScript for exact precision.
Founders/Managers: Adjust agent behavior by speaking or typing instructions in plain natural language.
Memory & Audit Logs: Every action taken by an agent is logged, traceable, and governed by agent-specific context and knowledge boundaries.

🛠️ How It Works
Describe Your Idea: Express what you want to build as if talking to a team member.
Clarify Requirements: SuperHands asks targeted follow-up questions to confirm specs rather than making assumptions.
Automated Build: The platform scaffolds the application code, database, and operational interfaces.
Agent Staffing: Purpose-built AI agents are assigned to handle tasks (e.g., taking bookings, processing waitlists, managing support tickets).
Autonomous Execution with Oversight: Agents run daily operations autonomously, escalating only high-stakes decisions to humans.

🖥️ Platform Tech Stack & Assets
The landing page features:
UI/Styling: Native CSS3 using custom properties, responsive flex/grid layouts, dynamic mesh gradient background animations, and responsive typography using Google Fonts (Space Grotesk, Inter, and JetBrains Mono).
Interactivity:
Interactive live org chart with toggleable Human-in-the-Loop (HIL) states.
Dynamic prompt input with automatic sample rotation.
IntersectionObserver scroll animations and parallax scroll progress bar.
Visuals: Inline SVG graphics representing platform console mockups, architecture diagrams, and custom iconography.

📋 Example Use Cases
Service Businesses: Booking apps for studios, clinics, or salons with automated waitlist and scheduling agents.
E-Commerce & D2C: Online storefronts with automated order updates, refund checks, and inventory tracking.
Internal Tools: Team expense trackers, inventory logs, and approval workflow tools.
